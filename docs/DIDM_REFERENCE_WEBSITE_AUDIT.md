# Live DIDM website reference audit

Assessment: 17 November 2026, Asia/Kolkata. This report distinguishes implemented code, verified behavior and work still required. No production deployment or database migration performed.

## Method and boundaries
The four requested URLs were opened with the web tool, followed by sitemap, DMI, professional, AI, contact, faculty and about pages. Gen AI/contact initially failed in that tool; direct public HTTP inspection subsequently succeeded. A read-only breadth-first crawl fetched 100 URLs discovered from the homepage/navigation and linked pages, four requests at a time, without submitting forms or executing enrollment/payment actions. Snapshot evidence: `next-generation/reference-inventory.json`. Each record includes status, heading hierarchy, form count, internal links, title, timestamp and a short identifying excerpt. The crawl stopped at 100, so this is NOT exhaustive traversal of every news article or external blog. All discovered unvisited URLs are listed below. Live claims were not treated as approved facts.

Screenshots captured the homepage at 1440, 768 and 390 pixels. These support homepage layout observations only; detailed responsive/interaction inspection of every reference page is not claimed.

## Findings
- Navigation exposes training tiers, branch selection, institutional/corporate services, credentials, media and student life. The repository covers most top-level journeys, but isolated course modules and the Varanasi branch need mapping.
- The reference puts a large embedded-text promotional banner above repeated content; the implementation prioritises readable text and course discovery while retaining the existing studio and real campus imagery.
- Public schedules mix expired absolute dates, open-ended availability and inconsistent day descriptions. No copied schedule or seat count is accepted as the new source of truth.
- Statistics, centre totals and program duration/accreditation claims differ across reference pages and repository datasets. Require written approval before publication as verified facts.
- Public sitemap.xml returns a not-found page with HTTP 200. Several linked pages do the same. Distinguish HTTP success from valid page content.
- Long faculty, placement and news pages make compact summaries and progressive disclosure valuable; preserve source attribution and do not invent outcomes.
- Course pages mix overview, curriculum, tools, comparisons and repeated enquiry forms. Reuse a common template over time rather than replacing all pages at once.

## Per-feature journeys, enhancements and dependencies

Design observations are based on rendered homepage captures and semantic structures for other pages, not invented visual inspection.
