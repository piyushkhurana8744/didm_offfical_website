# DIDM AI Counsellor Status

The counsellor is a deterministic server-side retrieval system, not a generative AI provider. It searches structured brochure modules, comparisons, tools/certifications, FAQs and institute information, plus the current course/centre catalog.

Responses include brochure page citations where applicable, disclose when page 12 does not contain lesson-level detail, distinguish historical workshop/milestone claims from current facts, and return an explicit non-fabrication fallback when no record matches. The chat UI displays retrieval provenance, citations, suggestions, links, accessible controls, mobile full-height layout and error states.

No API key is used or exposed.

Verified production responses include checkpoint 52 with page 12 citation, the Master/Advanced/Customized comparison with pages 14–16, and a refusal for an unsupported query.
