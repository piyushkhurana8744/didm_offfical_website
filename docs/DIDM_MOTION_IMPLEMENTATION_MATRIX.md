Shared MotionSection reveals headings and image masks on viewport entry. Content is server-visible; no page-load safety timer or universal whole-section fade. Card grids stagger on entry. Native browser scrolling replaces the synthetic Lenis driver. Reduced-motion paths remain readable and usable; the hero and campaign controls have explicit static modes.

The careers form prepares an email enquiry and explicitly asks the visitor to send it; there is no recruitment submission endpoint in the existing repository. It does not claim an application has been received.
