## 2. Policy & Compliance

1. **Zero Stock Imagery:** No generic or stock award images are utilized. Every photo depicts genuine DIDM founders, mentors, and named dignitaries.
2. **Third-Party Rights Protection:** External publication logos and editorial assets are handled strictly via semantic typography and sanctioned public embeds.
3. **Optimized Next.js Delivery:** All images use `<Image />` with explicit `sizes`, modern WebP/AVIF responsive format conversion, and blur placeholders where applicable.
